# Reference Company

这里是一家默认参考公司的组织骨架和操作手册入口。它用于展示 OrchestraCorp 的推荐组织方式，不是任何真实公司的当前组织，也不代表已经生效的政策。

## Maestro 入口与企业采用

[AGENT.md](AGENT.md) 是此目录的独立 Maestro 入口，[AGENTS.md](AGENTS.md) 为兼容入口。企业复制本目录的内容到自己的 Repo 后，入口仍在该 Repo 的根目录，不需要产品仓的任何父级文件。

本目录整体复制，保留内部路径；企业随后明确使命、责任、采用的规则、权限边界与 Stage 绑定。参考骨架不是已经接通后端的运行实例，复制或提交文件也不等于完成制度采纳或部署。

本模板采用 [MIT 许可证](LICENSE)，允许商业使用、修改和再分发。复制本目录或其实质部分时须保留版权声明及许可声明，完整复制时请一并保留 `LICENSE`。企业实例及其定制内容可以保持私有，许可证不要求公开企业资料。企业新增内容的权利由其权利人决定，采用外部资料时仍须遵守该资料的许可。

外层产品仓的 `examples/` 不属于企业运行必需内容。若采用外部材料，应把获准使用的知识和来源说明整理到公司 Repo 中，再经审阅使用。

## 内容目录

- `operating-handbook/`：默认组织手册的参考正文入口。
- `governance/`：参考公司的治理、授权和信息分类。
- `organization/`：参考公司的组织模型、岗位与决策权。
- `agents/`：参考 Agent 的能力与注册模板。
- `knowledge/`：参考公司的正式知识入口。
- `decisions/`：参考公司的决定与版本记录。
- `repositories/`：参考系统和仓库索引。
- `archives/`：允许归档的历史快照和回执。
- `departments/`：常规公司常见部门的使命、职责和接口骨架。
- `cross-functional/`：跨部门共同工作方法。

Stage 负责实际任职、当前任务、容量、授权和运行事实；本目录只描述参考公司的长期组织设计。
