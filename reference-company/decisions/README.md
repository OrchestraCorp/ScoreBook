# 决策目录

正式决策记录问题、背景、选项、依据、选择、影响、异议、审批、生效版本和复审时间。

建议区分：

- `proposal`：提案。
- `approved`：批准内容及其准确版本，不自动说明 Stage 已加载。
- `published`：已发布的内容及目标适用条件；实际生效以 Stage 记录为准。
- `superseded`：被新决策取代。
- `archived`：历史归档。

Maestro 可以整理提案；有权的人或治理角色批准内容，Stage 在核验后记录实际加载和生效。ScoreBook 可以保存带版本与时间的历史生效回执，不手工维护一份与 Stage 竞争的当前生效状态。
