# 默认组织操作手册

本目录是一家参考公司的默认组织操作手册。它提供可整体审阅和采用的组织运行基线，不是任何企业已经生效的政策。

企业采用时，应整体复制或分叉[公司入口目录](../README.md)及其内容，让 `AGENT.md`、本手册、治理配置、岗位契约和知识模板保持内部路径完整。随后填写公司使命、实际岗位、责任人、组织范围、业务系统、适用法律和运行参数，完成内部审阅后发布企业自己的版本。Stage 记录实际采用的版本和生效范围；当前模板尚未接入运行中的 Stage。

## 使用方式

- `charter.md` 是本手册的统一组织宪章正文；其他治理模板应引用本章，避免形成平行宪章。
- 本手册写“默认”时，表示参考公司建议的运行方式；企业可以调整，但应记录改变内容、原因、影响、负责人和复核日期。
- 企业必填事项包括使命、实际岗位与人员、组织范围、权限、预算、业务系统、数据分类、评价参数和外部要求。
- 薪酬、奖金比例、金额、具体审批额度和法律效力不由本模板预设。
- `ScoreBook` 保存规则和正式知识，`Stage` 保存当前任务、承诺、授权、运行与审计，`Maestro` 负责整理和提案，`Virtuoso` 支持员工与 Agent 工作。
- 企业的实时状态、个人记录、客户资料、合同原件、财务流水和凭据不应直接写入产品模板。

## 采用检查

企业发布采用版本前，至少确认：

- 每项持续责任都有负责人和替补路径。
- 任务、承诺、审批、验收和决策有统一记录位置。
- Agent、员工和第三方服务的权限与撤销边界已配置。
- 透明度、原始过程查阅、个人信息和知识复用规则已审阅。
- 资金、合同、客户、生产和高影响人员事项的人工责任已明确。
- 备份、恢复、事故、离岗和制度修订路径已演练或有计划。

具体工程接口、数据库字段、状态机和部署方式不在本手册中规定，由 `Stage`、`Maestro`、`Virtuoso` 和相关连接器的技术文档另行定义。
