# 信息分类模板

企业实例应至少区分以下信息层级：

| 层级 | 示例 | 默认处理 |
|---|---|---|
| public | 已批准的公共资料、公开产品信息 | 可按发布范围共享 |
| internal | 普通内部目标、任务、流程和组织知识 | 组织成员按职责访问 |
| restricted | 客户资料、未发布策略、个人评价、内部审计 | 按岗位、任务和目的授权 |
| locked | 密钥、薪酬、合同金额、财务原文、特殊申诉 | 指定主体访问，禁止自动跨域摘要 |

分类标签不代替真实访问控制。Stage、Maestro 和 Virtuoso 都必须执行来源对象的访问策略，派生摘要和检索索引也继承原始权限。

密钥只用于说明敏感程度，始终保存在受控凭据系统，不进入任何 Git 文件。其他受限原文须使用真正受限的仓库或业务存储；当前通用模板不承载这些真实数据。
