# OrchestraCorp 组织治理宪章模板

## 一、组织使命

> 待企业实例填写：组织存在的目的、主要服务对象和长期结果。

## 二、责任原则

- 人承担岗位责任和重要判断。
- Agent 在有效授权内处理信息、协调和执行。
- 重要承诺、事实和结果必须可追溯。
- 每项重要工作都有责任主体、验收依据和接管路径。

## 三、协作原则

- 默认由责任岗位承接跨岗位工作。
- Agent 可以在预先授权内协调；越界事项回到人。
- 直接沟通、异议和纠错是正式协作的一部分。
- 透明公开目标、责任、状态、风险和阻塞；敏感原文按权限隔离。

## 四、版本与生效

本模板不构成任何企业的生效政策。企业实例必须明确审批人、生效版本、适用范围、复审时间和撤销方式。
