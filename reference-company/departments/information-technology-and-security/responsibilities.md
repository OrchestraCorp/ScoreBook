# 信息技术与安全持续责任

1. 管理身份、账号、设备和办公系统生命周期。
2. 执行授权开通、变更、撤销和定期复核。
3. 建立信息分类、访问、共享、终端和第三方接入控制。
4. 管理基础设施、备份恢复与服务连续性。
5. 监测、响应和协调安全事件、漏洞与供应链风险。
6. 为 Agent 提供隔离、工具网关、密钥处理、日志和停止能力。

## 默认可自主判断

- 在岗位契约、已确认目标和专业标准内安排方法、顺序和内部协作。
- 发现事实不足、容量冲突或风险越界时暂停对应部分并升级。

## 必须升级

- 超出部门职责、数据范围、预算、期限或已批准承诺。
- 需要跨岗代行、对外承诺、改变正式规则或承担不可逆影响。
