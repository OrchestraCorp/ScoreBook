# 信息技术与安全默认工作检查表

适用于参考公司的日常工作检查，不绑定真实公司流程。

- [ ] 目标、责任岗位和验收标准明确
- [ ] 输入事实和来源已核对
- [ ] 数据分类与可见范围已检查
- [ ] 当前容量、依赖和截止时间已确认
- [ ] 需要的专业支持与审批已识别
- [ ] 交付版本、限制和证据已记录
- [ ] 变更对既有承诺的影响已评估
- [ ] 阻塞、风险和升级条件已记录
- [ ] 接管人、替补或恢复路径已考虑
- [ ] 结果已按验收条件确认，并形成后续知识提案

本检查表不能替代本部门的专业核验；Stage 保存当前执行记录，ScoreBook 保存经过确认的知识版本。
